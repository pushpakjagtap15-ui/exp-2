## 🛠️ Python Environment & Execution
Python programs can be executed in two main ways:  
- **Interactive Mode:** Code is typed line by line, and results are displayed immediately. Useful for testing small ideas.  
- **Script Mode:** Code is written in a `.py` file and executed all at once. Suitable for larger projects.  

Common tools used: **VS Code, Google Colab, Jupyter Notebook**.  

---

## 📝 Comments
Comments are notes for programmers that Python ignores during execution.  
- **Single‑line comments:** Begin with `#`.  
- **Multi‑line comments:** Written using triple quotes `""" ... """`.  
They improve readability and documentation of code.  

---

## 📂 Variables and Data Types
- **Variables:** Named storage locations for data.  
  - Rules: Must start with a letter or `_`, cannot start with a number, and are case‑sensitive.  
- **Data Types:**  
  - **int** → Whole numbers (e.g., 10, 20)  
  - **float** → Decimal numbers (e.g., 99.9)  
  - **str** → Text (e.g., "Hello")  
  - **bool** → Logical values (True/False)  

Python automatically detects the type of data stored in a variable.  

---

## 🔢 Operators
Operators are symbols used to perform operations on data:  
- **Arithmetic Operators:** +, -, *, / (basic math)  
- **Relational Operators:** ==, >, < (comparison)  
- **Logical Operators:** and, or, not (combine conditions)  
- **Bitwise Operators:** Work at the binary level (e.g., &, |, ^).  

---

## 📊 Input and Output
- **Output:** Displayed using `print()`.  
- **Input:** Taken from the user using `input()`.  
  - Note: Input is always read as text, so conversion to `int` or `float` is required for calculations.
